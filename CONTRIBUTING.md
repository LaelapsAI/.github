# Contributing

The LaelapsAI repositories are built by the Laelaps team. Outside
contributions are by arrangement; to report a security issue, see
[SECURITY.md](SECURITY.md).

## Issues

Open an issue with one of the forms: **Bug**, **Feature**, **Task** or
**Epic**. Each sets the matching issue type and adds the issue to the team's
board. Describe the outcome, not the solution, and fill in "Done when". An
Epic groups the issues that together deliver one outcome; the work happens in
its sub-issues.

## Pull requests

- Link the issue it belongs to with `Closes <repo>#<number>` in the
  description.
- Set an assignee and at least one descriptive label.
- Fill in every section of the pull request template.
- Get the review the repository requires (code owners) and green CI.

Members find the full conventions in the internal `LaelapsAI/claude-plugins`
repository (`plugins/laelaps-product/skills/product/conventions.md`).
