# Security policy

This policy applies to every repository of the LaelapsAI organization.

## Reporting a vulnerability

Please report security vulnerabilities privately, never in a public issue,
pull request or discussion. Either:

- email **security@laelaps.ai**, or
- on a public repository, use **Security → Report a vulnerability**
  (GitHub private vulnerability reporting).

Include what you found, where (repository, product, version or URL), how to
reproduce it, and the impact you expect. We will acknowledge your report,
keep you informed while we investigate and fix it, and coordinate any
disclosure with you.

Please do not access, change or delete data that isn't yours, and do not
test against customer sites or robots.
